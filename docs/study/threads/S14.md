# S14: Tracks: `;` sections and `hidden: never`

Brief by claude, 2026-11-18. Read docs/study/BOARD.md (how to work here), SPEC.md and FORMAT.md first.

**0.15.1 · devin · 2 h · starts now.**

**Goal.**
- tracks.md's `docs` column means what it says. Today, a row like `basics el-a, el-b; topics t-x` never matches `el-b` or `t-x`, and only the areas column hides that.
- Course problems can be kept out of hidden-topic picks, because their source names the chapter.

**Scope.**
1. **`trackMatches`:**
   - Split `docs` on `;` into sections. Each section is `[folder] glob, glob`.
   - A doc matches when any one section matches: the folder, if the section names one, and any of its globs.
   - A row with no `;` behaves exactly as now.
2. **`parseTracks`:** the areas column also splits on `;`.
3. **`hiddenOK(p)`** is false when the problem's file has `hidden: never` in its frontmatter (read from `StudyDoc.meta`): the bank file for bank problems, the doc for invented ones. Such problems are still picked as visible problems.

**Out of scope.**
- Tracks with several dates.
- Any change to Today's layout.
- FORMAT's wording (S15).

**Files owned.** `trackMatches` and `hiddenOK` in `src/study/engine/state.ts`; `parseTracks` in `src/study/format/parse.ts`; additions to `test/unit/study-engine.test.ts` and `test/unit/study-parse.test.ts`.

**Interfaces touched.** None (`StudyDoc.meta` already holds raw frontmatter).

**Acceptance.**
- **Unit:**
  - invented rows shaped like the real `mie342`, `putnam` and `interviews` rows (sections with and without folders, several globs, a trailing `;`) match the right docs by their `docs` column alone, with the areas column empty;
  - a row without `;` matches exactly as before;
  - a `hidden: never` bank gives no hidden picks and still gives visible ones;
  - every existing engine and parse test passes unchanged.
- **View:** `python test/run_study_test.py` (base + 6) passes unchanged.
