# S38: Progress script for the laptop planner

Brief by claude, 2026-11-20. No release: a laptop script only; nothing in the plugin changes.

**Goal.** A planner on the laptop can tell, from the study folder alone, what is done in each doc and how long things took, read through the plugin's own parser and engine.

**Scope.** `scripts/study-progress.mjs <study root> [--day=] [--minutes=]` prints one JSON object: per doc its size (prose words, proof steps, examples, derives, recalls), the proofs with a finished fog, and its Try list with what was settled; every basic's stage and due date; open calls; the timed events (settles, drills, katas, fogs) with their device-local day; Today's drills and picks for the day; the tracks. It exports `loadLib()` and `progress(root, day)`. It never writes into the root. `study-scan.mjs` is not changed (its `readStudy` is imported).

**Out of scope.** Planning rules, estimates and anything private: those live in the planner, outside this repo.
